# Day Off Dev

**Shipped on our days off.**

We're a small Toronto studio building web apps, phone apps, websites and games — things that save people time, things that spark a little creativity, and ideally both.

🌐 **[dayoffdev.com](https://dayoffdev.com)** · 🎮 **[dayoffgames](https://dayoffgames.com)**

---

### What we build

| | |
|---|---|
| 📱 **Phone & Mac apps** | Native iOS / macOS apps — Swift, SwiftUI, HealthKit |
| 🌐 **Web apps & sites** | Fast, accessible front-ends with React — live or local-first |
| ⚙️ **Tools & automation** | AI workflows, scripts and utilities that cut busywork |
| 🎮 **Games** | Small indie games, released under dayoffgames |

### What we build for

- **Efficiency** — give people time back
- **Unique** — made for a specific person and a specific problem, not a template
- **Creativity** — code is a creative medium
- **Fun** — when the builder enjoys it, the user can feel it
